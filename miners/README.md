# HobbyHash miners

Official reference miners for HobbyHash Coin V6 (multi-algorithm race).

| Folder | Algorithm | Pool | Download |
|--------|-----------|------|----------|
| [`hobc-rxminer/`](hobc-rxminer/) | RandomX (CPU) | `pool.hobbyhashcoin.com:5559` | https://hobbyhashcoin.com/downloads/miner/randomx/ |

These are **not** XMRig / SRBMiner / lolMiner forks. Each miner speaks HobbyHash’s own stratum and matches node consensus hashing.

Prebuilt packages (Linux + Windows) are published on the HobbyHash downloads site. This folder is the open source for the RandomX CPU miner.
